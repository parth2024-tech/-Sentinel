# Contributing to Sentinel

Thank you for your interest in contributing to the Sentinel Platform! 

## Getting Started
1. Fork the repository
2. Install dependencies using `pnpm install`
3. Check out a new branch for your feature or bug fix

## Development
- We use `pnpm` for package management in our monorepo.
- Make sure to run `pnpm run build` and ensure tests pass (`pnpm run test`) before submitting a pull request.
- All code must pass `eslint` validation without warnings. 

## Pull Requests
- Please provide a detailed summary of your changes in the pull request body.
- If your PR introduces a new feature, include a test case verifying its behavior.
- Link any related open issues in your PR description.
